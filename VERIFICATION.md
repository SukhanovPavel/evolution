## Известные ограничения

- Демо живёт только в памяти вкладки. При перезагрузке сбрасывается; реальную запись в БД не имитирует.
- Full offline, background sync, native push/health/camera/app stores не входят в MVP. Добавлен Web Push с Supabase Cron и настраиваемым расписанием. Получение push на физическом устройстве требует ручной проверки владельцем.
- JSON-редактор администратора проверяет структуру; полноценный WYSIWYG/медиа uploader не входит в этот MVP. Optional catalog images/media поддерживаются в схеме; Storage bucket и политики подготовлены.
- Аллергии сопоставляются по названиям ингредиентов и тегам; не заменяют проверку упаковки/перекрёстного загрязнения. Ограничения и боль обрабатываются консервативно, не диагностируются.
- Минуты и завершение — пользовательские отметки/таймер, без биометрического подтверждения. Диапазоны прогресса ограничены 366 днями.
- Полный `npm audit` показывает 5 high записей в одной цепочке dev-инструментов `eslint-config-next → @next/eslint-plugin-next → fast-glob → micromatch → braces`, advisory GHSA-vfj7-8cjw-p6xm. Production audit чист. Рекомендация audit требует отката ESLint config на Next 14; такой несовместимый откат не применялся. Перед обновлением инструментов проверяйте совместимый патч.
- Vitest на Node 25 выдаёт предупреждение jsdom/localStorage, Playwright — NO_COLOR/FORCE_COLOR; тесты проходят. Это предупреждения окружения, без вывода пользовательских данных.
